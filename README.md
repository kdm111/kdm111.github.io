# 박준수 · Robotics Portfolio

2026년 9월 21일의 25페이지 포트폴리오를 바탕으로 만든 GitHub Pages 사이트입니다.

2026년 9월 25일 웹 본문에 VicPinky 담당 범위와 코드 폴더 링크, LARO-BOT의 한계·개선 방향을 추가하고 표기를 정리했습니다. 기존 페이지 번호와 영상 링크는 유지하며, 한계·개선 방향은 14페이지 아래 보충 내용으로 제공합니다. VicPinky 담당 범위에 AMR 자율주행 경로·계획을 명시하고, 통신 병목 결과에 위치 정보 수신 9Hz → 40Hz 회복을 반영했습니다. 17페이지 구조도의 연결선을 다시 구성했으며 사이트의 PPTX 다운로드 버튼은 제거했습니다.

전체 25페이지의 연결선을 점검해 누락된 화살표와 잘못된 좌표를 수정했습니다. 주 흐름은 위→아래·왼쪽→오른쪽으로 읽도록 도형 배치를 조정했습니다. 18·20페이지는 두 번째 행도 왼쪽에서 시작하도록 배치하고, 행 사이를 곡선으로 연결했습니다. 10페이지 행동 순서도 오른쪽 화살표를 사용합니다. 실제 양방향 통신과 피드백의 방향은 유지합니다. 모바일 흐름도는 한 열로 배치하고 단계 사이에 아래 화살표를 표시합니다.

- PC: PPTX의 도형 좌표, 이미지, 문구, 색상을 SVG와 HTML로 재현합니다. 본문 텍스트는 선택할 수 있고, 영상은 원래 위치에서 재생됩니다.
- 모바일·태블릿(900px 이하): 읽기 좋은 본문, 가로 넘김 카드, 세로 흐름도, 모델 비교 표를 사용합니다. 시연 버튼을 누르면 우측 영상 패널이 열리며 스와이프·이전/다음 버튼으로 영상을 전환합니다.
- 영상 30개: 화면에 보이는 영상 하나만 무음으로 자동 재생합니다. 기본 영상 컨트롤로 재생·일시정지·탐색·음량·전체 화면을 조작할 수 있습니다. 화면 밖 영상과 백그라운드 탭은 재생을 멈춥니다.
- 상단 자동 재생 설정은 브라우저에 저장됩니다. 동작 줄이기·데이터 절약 설정에서는 자동 재생을 기본으로 끕니다. 브라우저가 자동 재생을 차단해도 수동 재생이 가능합니다.
- 기존 PPTX 파일은 외부 링크 호환성을 위해 보관하며, 사이트에는 다운로드 버튼을 표시하지 않습니다.

## 이번 영상·링크 변경

19페이지의 **명령 완료 조건 확인**, 23페이지의 **가상 로봇 검증** 녹화를 추가했습니다. 실제 FMS를 가상 로봇과 테스트 입력으로 실행한 영상이며 실물 촬영과 구분해 표시합니다.

기존 내장 영상 8개는 웹 MP4와 영상 스트림 SHA-256이 일치합니다. 기존 MP4 경로를 유지하고, PPTX의 MP4 링크는 해당 영상을 자동·수동으로 재생할 수 있는 `watch.html` 주소로 연결했습니다. 14페이지의 영상 3개와 19·23페이지의 화면·제목에 빠진 링크를 추가했습니다. 20·22페이지는 대표 프레임을 대조해 기존 영상이 맞음을 확인했습니다.

원본 슬라이드는 16:9 좌표를 사용합니다. 영상을 제외한 사진과 도형은 원본 좌표를 따르며, 웹 글꼴은 Arial / Apple SD Gothic Neo 등을 대체 글꼴로 사용합니다. 원본 Arimo의 자간과 굵기를 반영하되, 운영체제의 한글 글꼴에 따라 미세한 차이가 있을 수 있습니다.

이전 PDF·영상·React 빌드 파일은 외부 링크 호환성을 위해 보관하고 있습니다. PPTX 다운로드 버튼은 사이트에서 제거했습니다.

## 검증

연결선 수정 후 Chrome 7개 화면 폭(320–1440px), WebKit 2개 화면 폭에서 각 25페이지를 확인했습니다. 새로 정리한 방향 화살표 55개, SVG 좌표·마커 참조, 처리 단계 배치, 모바일 세로 흐름, 페이지 넘침과 목차 링크를 검사했습니다. 10·18·20·21페이지의 영상 패널 열기·닫기도 두 브라우저의 PC·모바일 화면에서 통과했습니다.

9월 25일 변경은 Chrome 7개 화면 폭(320–1440px)과 WebKit 2개 화면 폭에서 확인했습니다. 담당 문구·수신 주기 표시, 가로 넘침, 목차 대상, 영상 패널 열기·닫기, 메인·영상 페이지의 PPTX 링크 제거를 포함한 브라우저 검사 17개를 통과했고, 로컬 리소스 경로도 확인했습니다.

9월 21일에는 Chrome 48개, WebKit 23개의 브라우저 검사와 PPTX·영상 66개 검사를 통과했습니다. 320–1440px 화면에서 가로 넘침, 자동·수동 재생, 사용자의 일시정지 유지, 화면 밖 정지, 영상 패널 전환, 키보드·포커스 복귀, 필터, 장면 이동, 당시 다운로드를 확인했습니다. Chrome에서 전체 30개 영상을, WebKit에서 신규 영상과 대표 형식 5개를 재생했습니다. 실제 iPhone·Android 기기 및 PowerPoint 앱의 슬라이드 쇼는 별도로 실행하지 않았습니다.
