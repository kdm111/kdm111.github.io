LARO-BOT · SYSTEM ARCHITECTURE

  1. INPUT

    사용자 명령

    “빨간 블록을 선반으로 옮겨줘”
    한국어 · 영어 · 일본어 등

  2. arm_agent

    계획 생성·검증

    명령을 로봇 행동으로 변환

  3. arm_skills

    행동 실행

    Pick · Place · MoveTo
    행동 요청을 실행하고 진행 상태와 결과 반환

  4. ROBOT CONTROL

    목표점 이동

ROBOT CELL · FEEDBACK

실제 동작과 결과 확인

그리퍼 상태와 카메라의 물체 위치로 결과 확인. 반환된 결과에 따라 다음 행동 진행 또는 중단

계획 → 실행 → 인지와 센서 피드백 → 결과 확인자연어 명령을 검증된 행동 계획으로 바꾸고, 실행 결과에 따라 다음 행동이나 복구 여부를 결정합니다.

LARO-BOT · SIMULATION / REAL ROBOT

Gazebo와 실물에서 확인한 로봇팔 동작

작업 예시“빨간 블록을 카운터로 옮겨줘”

Gazebo · 전체 작업 흐름 확인명령 → 집기 → 이동과 놓기 → 결과 확인

실물 · 집기·놓기 실행물체를 집고 내려놓는 실제 동작 확인

서로 다른 시점의 시연입니다. 왼쪽은 3배속, 오른쪽은 원속도이며 실행 속도를 비교하는 영상은 아닙니다.

LARO-BOT · PLAN VALIDATION

OLLAMA · 구조화된 계획

pick(red_block)
place(red_block, shelf)

초기 명령 계획 최대 2단계

시스템의 계획 검증

  • JSON 형식과 필수 인자 확인
  • 허용된 행동인지 확인
  • 인식된 물체와 등록된 목적 구역 확인
Gemma4 26B / 기존 평가 기록220 / 242 90.9%
10개 언어 평가 / 전체의 부분집합59 / 60 98.3%

60개 다국어 사례는 전체 242개 평가에 포함됩니다. 케이스별 3회 모두 통과한 LLM 응답 평가 기록이며, 실물 작업 성공률과는 구분합니다.

LARO-BOT · AUTONOMOUS CLEANUP

로봇 자율 행동: 작업 구역에 남긴 물건을 스스로 정리

  1. 대기 상태에서 2초 이상 관찰

    work 구역에 머무는 물체를 정리 대상으로 선택

    red_block → shelf / green_block → bin

  3. 집기와 놓기 후 지정 자세로 이동

    Pick → Place → MoveTo(복귀 자세)

  4. 동작 후 최종 배치 확인

    카메라 인식 결과로 목적지 배치 여부 확인
